# term-rewind-
**term-rewind** 是一款面向终端命令与 AI 编程 Agent 的按次文件快照与选择性撤销工具，采用零第三方依赖的纯 Python 实现。在未提交 Git 的本地试错或 Agent 自动改码阶段，它会在命令或工具执行前后保存轻量快照，支持在终端时间线、CLI 或 Windows 桌面端与贴边浮窗中查看 Diff 并精确回滚单个文件。恢复前会自动检测后续改动冲突与路径安全，强制覆盖也会归档当前内容并支持再次撤销。项目内置零依赖 MCP 服务及 Claude Code / Shell 钩子，支持分步归因、并发调用配对以及桌面端实时输出与取消，是与 Git 互补的即时代码安全网。
