# term-rewind · Windows 桌面版

双击桌面图标或本目录的 **`term-rewind.exe`** 打开应用。进入 **项目总览**，点 **加载示例**。操作记录页会显示一条失败的命令、受影响的文件和 Diff。选中 `draft.md`，点 **恢复所选文件** 即可找回草稿。试玩项目都放在本文件夹的 `demo-data` 中。

用 **打开项目** 选择自己的目录，切到 **操作记录** 后点 **运行命令**。桌面版适用于执行后会退出的命令，输出可从 **命令输出** 查看。执行 Agent 任务前也可以点 **开始任务**，完成后选中这条进行中的记录，再点 **结束所选记录**。

应用目录包含 Windows x64 运行环境，无需另外安装 Python。移动应用时请移动整个目录。项目历史与命令行版共用，同一个项目目录可以在两个入口查看。命令输出会在退出应用时清除，文件差异和恢复记录仍可查看。

## 桌面浮窗

在 **设置** 中勾选 **启用桌面浮窗**，屏幕边缘会出现小胶囊。单击胶囊会展开菜单，显示当前项目和文件选择状态。菜单提供打开项目、加载示例、运行命令、开始或结束任务、查看历史、查看差异、命令输出、恢复所选文件、刷新、打开主窗口、关闭浮窗和退出。

项目路径、命令输入、任务、历史、Diff、命令输出、文件多选和恢复确认都在浮窗里完成。浮窗里的返回键可逐层返回，按 Esc 返回上一页或收起菜单。运行命令前先打开项目，恢复前先选中要恢复的文件。

拖动胶囊或菜单标题栏，松手后会自动贴边。应用会记住开关和位置。浮窗开启时，主窗口的关闭键会将主窗口隐藏。浮窗的入场、展开、菜单项逐个显示、收起、悬停和贴边动效遵循 Windows 的动画设置。

应用会按上次的浮窗设置启动。浮窗开启时，下次启动直接显示胶囊，可从菜单选择 **主窗口**。同一个 Windows 登录会话只运行一个桌面实例。重复双击快捷方式会唤回当前窗口，或展开正在运行的浮窗。

## 终端试玩

双击 **`demo.cmd`**。它会在本文件夹的 `demo-data` 下新建一个示例项目。演示脚本会改坏一份配置、删除一份草稿、生成一个文件，然后报错退出。演示接着手动改一次配置，让你试试如何只找回草稿。

1. 按回车打开时间轴，再按回车打开失败的命令。
2. 用方向键选中 `D  draft.md`，按回车查看删掉的内容。
3. 按 **U**，再按 **Y** 恢复这份草稿。用 **Esc** 返回或退出。成功后，演示会确认草稿已恢复，而且后来修改的配置仍在。

直接运行 `demo.ps1` 会自动验证同样的流程。

## 在自己的项目中试用

在 PowerShell 中切换到你要保护的项目目录。将下面第一行的路径换成实际安装路径。

```powershell
$desktop = [Environment]::GetFolderPath("DesktopDirectory")
$rewind = Join-Path $desktop 'term-rewind\rewind.ps1'
& $rewind run -- python.exe .\clean_data.py
& $rewind list
& $rewind diff <记录ID>
& $rewind undo <记录ID> --file draft.md
& $rewind
```

`<记录ID>` 换成 `list` 给出的 ID，不带尖括号。可重复传 `--file` 选择多个文件，省略则选择这条记录的全部文件。撤销前会检查所选文件是否已变动。检测到冲突时会列出路径并停止。成功的撤销也会生成一条记录。

`run` 接受外部程序。运行 PowerShell 脚本可用 `run -- pwsh.exe -File .\script.ps1`。默认保护并在当前目录执行。可在子命令前传 `--root 路径` 指定项目目录。

## 记录一次 Agent 任务

```powershell
$id = & $rewind begin 'Agent: fix login'
# 让 Agent 在当前项目里执行任务，等待它完成
& $rewind end $id
& $rewind diff $id
```

这会记录两次快照之间的项目改动，包括 Agent 直接写入的文件。如果人和 Agent 同时改动项目，Diff 会包含两者。此版本由使用者显式开始记录。

快照保存在本机的 `%LOCALAPPDATA%\term-rewind`，包含文件原始内容和执行过的命令参数。可用 `--store` 指定项目外的其他目录。试玩数据和试玩快照都留在本文件夹的 `demo-data` 内。可在设置页点击清理或运行 `rewind gc --keep 20` 手动保留最近 20 条记录并清理未引用对象。

恢复采用单文件原子写入与路径复核；多文件恢复若中途中断会留下 `partial`（部分完成）记录，可通过 `rewind end <记录ID>` 对齐状态。单次快照上限为 5,000 个文件或 128 MiB，单文件超过 8 MiB 会跳过。符号链接、目录联接、`.git`、`.env*` 的常见命名以及几个依赖和缓存目录也会跳过（可在项目根目录放 `.rewindignore` 自定义忽略规则），Diff 会标出实际跳过的路径。`term-rewind` 不能替代 Git 或完整系统备份；Git 分支、暂存区、权限和外部服务状态超出这版的恢复范围。
